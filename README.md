# mahfoudhconsult portfolio: The Stack

Static multi-page site plus one Netlify Function (the audit).
- Pages are generated by `node tools/build.mjs` (already run; commit the .html files).
- `netlify/functions/audit.mjs` powers /audit.html at /api/audit. No key needed. Optional env var PSI_KEY adds Google PageSpeed.
- Forms: contact and audit-report use Netlify Forms.
Upload everything in this folder to the repo root (replace existing files), then Netlify redeploys.
